# OnePlus 15 Slider HBM Unlock

一加 15 系统亮度滑块激发亮度模块。

- 模块名称：`OnePlus 15 Slider HBM Unlock`
- 版本：`1.5`（`versionCode=150`）
- 作者：傻瓜我爱你呀喵
- 最高激发亮度：`1800nit`

## 功能

- 解锁系统完整亮度调节范围。
- 跟随系统亮度滑块实时调节，不强制固定最高亮度。
- 处理应用亮度限制，让应用跟随系统亮度滑块。

## 适配

OnePlus 15（包括 `PLK110`、`OP60FFL1` 等机型属性）。

## 安装

在 KernelSU 或兼容的 Root 模块管理器中刷入 [Release ZIP](https://github.com/AaTempSpoof/oneplus15-brightness-unlock/releases/latest)，重启后调节系统亮度滑块即可。
